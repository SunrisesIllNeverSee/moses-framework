## What This Is

This is the **canonical source code for the MO§ES™ intellectual system**. It is not a paper, not a marketing site, not a documentation dump. It is a machine-readable ontology, provenance ledger, claims registry, and prior-art map that establishes the framework's primitives, relationships, priority, boundaries, falsifiable claims, and extensions.

The repo becomes the canonical state. Human-readable outputs (papers, websites, briefings) are generated from it, not the other way around.

## Claims Discipline

Every substantive claim carries exactly one state:

| State | Meaning |
|-------|---------|
| `DEFINED` | Introduced by the framework; true by construction |
| `DERIVED` | Follows logically from accepted definitions/propositions |
| `OBSERVED` | Empirical result, not yet replicated at scale |
| `SUPPORTED` | Replicated or scaled empirical evidence |
| `HYPOTHESIS` | Testable but not yet established |
| `SPECULATIVE` | Productive idea, not yet formalized or testable |
| `EXTERNAL` | Borrowed from prior literature |

## Prior-Art Discipline

Every important term is tracked with: term, canonical MO§ES meaning, first internal usage, first public disclosure, external prior usages, field, conceptual overlap, explicit distinction, citation, institutional anchoring, trademark/patent relevance, and status (`OWN` / `DEFINE` / `BORROW` / `AVOID` / `WATCH`).
